Taruh file logo resmi di folder ini dengan nama PERSIS seperti berikut:

  skintific.png
  somethinc.png
  avoskin.png

Format lain juga dikenali otomatis: .svg, .webp, .jpg (pakai nama yang sama).
Disarankan logo berlatar transparan, tinggi sekitar 100-200 px.
Jika file belum ada, website menampilkan nama merek sebagai teks (tidak error).
Ambil logo dari situs/akun resmi masing-masing brand.
